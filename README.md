# Decision Modelling — Simulation Part

Course materials for the simulation and simulation-optimization component of
the Master's course "Decision Modelling" (Operations and Supply Chain
Analytics programme).

## Structure

- `notebooks/` — one Jupyter notebook per session (markdown + code cells)

## Sessions (simulation part, 12 x 2h)

1. Introduction to Simulation & Business Process Modeling
2. Modeling Randomness & Input Analysis
3. Monte Carlo for Decision-Making & Risk
4. Quantifying Flow: Capacity & Cycle Time
5. Queueing Theory for Simulation
6. Introduction to Discrete-Event Simulation (SimPy I)
7. DES Modeling in SimPy II: Multi-Server & Complex Queues
8. Output Analysis for Terminating Simulations
9. Output Analysis for Steady-State Simulations
10. Scenario Comparison & Variance Reduction Methods
11. Advanced DES Practice: Inventory or Production Line Simulation
12. Verification & Validation (capstone)

Simulation-based optimization is covered separately in two integration
sessions taught jointly with the mathematical-programming part of the course.
